Web-calculator:\
Functional web calculator with a clear interface built with HTML , CSS , JS .

Features:\
-Basic arithmetic operations (addition, substraction, multiplication, division)\
-Parentheses support for grouped expressions\
-Clear / reset display button ('C')\
-Clean button layout with a dedicated read-only screen 

Technologies:\
-index.html): Structure of the calculator layout and buttons\
-style.css): Styling, colors\
-script.js): Calculation logic and button event handling

How to run locally?\
1.Clone or download the 'Web-calculator' repository.\
2.Open 'endex.html' in your browser (or use "Live Server" in VS Code)
